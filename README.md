# EKSEN 3.0 — YKS Curriculum OS

Bu sürüm EKSEN 2.0'ın müfredat/animasyon mimarisini büyütür.

- 26 ayrı ders/test alanı
- 183 ünite
- 751 konu
- 111 konuya bağlanan animasyon motoru
- Ders → ünite → konu hiyerarşisi
- Her konu 5 aşamalı interaktif döngü: Keşfet → Manipüle Et → Tahmin Et → Uygula → Transfer
- TYT, AYT ve 5 YDT dili ayrı kataloglanmıştır.
- 2026-2027 hibrit program durumu veri modelinde tutulur: 9-11 TYMM, 12. sınıf önceki program.
- Bu katalog YKS hazırlığı için normalize edilmiş kapsam haritasıdır; resmî öğrenme çıktılarının birebir metni değildir.
